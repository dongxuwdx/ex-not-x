# Ex not X · 本地原型 v2（网页细调 11.1）

直接双击 **dist/index.html** 用 Chrome / Safari / Edge 打开即可，不需要联网、不需要服务器。
（需要浏览器开启 WebGL；漂流论坛的水面和小鸭是实时 3D 渲染。）

## 页面与操作

- **今日问题（index.html）**：左上角 Ex not X；去掉了顶部导航和“背面/转到正面/拖动”提示。白色半透明弧形箭头提示可以拖动翻转卡片；卡片是玻璃质地，问题一行居中，按钮为 赞同 / or / 反对。背景是程序绘制的粉彩未来城市，天空撕开一道裂口，里面流动着代码和马赛克；一只真实肌理的手指向卡片。选择立场后直接进入漂流论坛。
- **漂流论坛**：贴近水面的视角，水面上下左右起伏、玻璃质感的棋盘格河床；绿鸭=赞同、蓝鸭=or、红鸭=反对（自由论坛为黄鸭），鸭子大小随热度和讨论度变化，会随水流打转并自然漂出画面。顶部显示今日问题和实时投票比例。
  - 轻轻上滑：下一批小鸭；大幅上滑：自由论坛；轻轻下滑：倒回刚漂过的；大幅下滑：双手之间（鼠标滚轮同理，滚得少=轻，滚得多=大幅）。
  - 按住一只鸭拖到左右岸边：帖子留在“岸边”，随时点开。
  - 点鸭子或标题打开帖子卡片：+1鸭（嘎一声、小水花）、看看这位bro/sis/这只鸭、顺水回一句、漂过去；关闭按钮悬停提示“回到岸边”；“⋯”里有“少给我看这类”（可撤销）和“举报”。
- **双手之间**：首次进入有左右滑引导；左手为玻璃外壳包裹的电路板。左滑=我的，右滑=写点什么，上滑=回到漂流论坛。
- **我的**：底图直接用 doc 里的沙漠银马图（已去掉手写标注）；图里的 UFO 抠成单独一层，会漂浮转动，光束里的个人标签绕圆柱体转动；“Who knows”下方每次随机一句小字；立场报告、漂出去的话 / 推荐信 / 举过的鸭掌；“编辑资料”可改星座、MBTI、地区、年龄、性别、爱好、惯用手。
- **写点什么**：复古桌面风格。推荐信（标题与开头提示轮换、纸张纹理、按字数变化的提示、“只有你和这只鸭知道”），一段自由讨论（标签按钮代替下拉菜单，停笔 30 秒提示去捞卡），无从讲起（捞一张卡 / 一步一步来 / 从一样东西开始 / 卡片篮，可拖动排序、串成正文、带去推荐信或自由讨论）。右下角小鸭打字时点头、停久了打哈欠。发出后信纸折进小鸭背包，小鸭游出画面，进入自由论坛：“它已经出发了。也许某一天，会有人读到。”

## 说明

- 帖子、人物、投票数都是演示数据；发帖、回复、点赞只在本次浏览中有效，刷新后清空。卡片篮会保存在本机浏览器（localStorage）。
- 今日问题和“我的”的底图直接取自 doc（`assets/ref-*.jpg`，处理说明见 `tools/README-images.md`）。城市图右下角保留了原图的小红书/作者水印。
- 修改源码后运行 `npm run build` 重新生成 dist；`node --test tests/*.mjs` 运行测试。`tools/embed.py` 用于重新生成内嵌图片（为了在 file:// 下也能用于 WebGL 和遮罩）。
